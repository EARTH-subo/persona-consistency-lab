# 版权隐去说明

本仓库是**方法论文档**，不是完整可运行版本。以下内容在公开时被**主动隐去**，原因全部是版权，而非内容质量问题。

---

## 一、隐去了什么

| 隐去内容 | 说明 | 为什么隐去 |
|---|---|---|
| **人设卡全文**（v1 / v2） | 由官方角色详情、角色故事、角色语音、官方影像整理而成，逐条标注出处并附引用原文 | 整理稿中包含成体系的官方原文引用，属他人著作权内容 |
| **本地语料库** | 抓取得到的官方文本转录页（259 页） | 直接转载他人作品 |
| **检索索引** | 全文索引、向量索引 | 由语料生成，可反推原文 |
| **语料抓取与建库实现** | 抓取、清洗、建索引的完整脚本 | 不希望本仓库成为批量获取官方内容的工具 |
| **官方影像拆解稿** | 对 4 部官方影像的逐帧拆解，含大量影像文案引用 | 含官方影像文案引用 |

以上内容均在本地**完整存在且实际运行过**，只是**不适合公开分发**。

## 三、为什么评测报告里有些地方看不到了

评测的原始结果（模型回复）中，有少量内容**复述了官方台词**。这部分已在公开版本中替换为「原文因版权不展示」的说明。

**这不影响结论**：报告中的分数、规律与失分模式，全部保留。

## 四、为什么不提供抓取实现

抓取他人在线内容涉及**目标站点的使用条款**与**内容著作权**。本仓库是个人作品展示，**不应成为批量获取官方内容的工具或指引**，因此不提供完整抓取实现，也不提供复现步骤。

如果希望了解这套检索方案在工程上如何设计（混合检索、融合排序、索引选型等），可以看 README 第四节的方法说明，或直接联系作者交流。
