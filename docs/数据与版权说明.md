本仓库是**方法论与工程框架**的展示，**不包含**《崩坏：星穹铁道》的官方文本数据。这里说明具体边界与原因。

---

## 一、哪些内容没有入库

| 类别 | 文件（本地存在，未入库） | 原因 |
|---|---|---|
| 抓取语料 | `rag/corpus.jsonl`（259 页） | 官方文本转录镜像，属他人著作权内容 |
| 全文索引 | `rag/himeko_fts.db` | 由语料生成，含等量文本 |

| 官方文本整编 | `姬子_官方文本存档.md`、`姬子_官方资料汇编_v1.md` | 官方文本的批量整理，接近转载 |

以上文件均已写入 `.gitignore`，**不会随仓库分发**。

## 二、哪些内容入库了，为什么

| 内容 | 性质 |
|---|---|
| 全部代码（`jizi_agent.py`、`rag/*.py`、`人设一致性测试/*.py`） | **本人原创代码**，展示工程实现 |
| `姬子_人设卡_v2.txt` | 对官方公开资料的**分析整理**，逐条标注出处；为角色扮演研究与技术演示用途 |
| 测试题集与判据（`persona_test_v2.jsonl` 等） | **本人原创题目与判据**，不含官方原文的长篇转载 |
| 评测报告 | **本人原创分析文本** |
| `rag/himeko_tasks.json` | 抓取任务的**页面元数据**（标题/URL/字数），不含正文 |

**取用原则**：仓库提供的是「怎么抓、怎么清洗、怎么建索引、怎么评」的代码与文档，而不是「已被抓取好的内容」本身。想要运行完整链路，需自行抓取公开资料。

- 它是**官方文本的转录镜像**，**不是官方数据库**；
