本仓库是**方法论与工程框架**的展示，**不包含**《崩坏：星穹铁道》的官方文本数据。这里说明具体边界与原因。

## 一、哪些内容没有入库

| 类别 | 文件（本地存在，未入库） | 原因 |

| 人设卡 | `姬子_人设卡_v2.txt`、`姬子_人设卡_v1.txt` | 由官方公开资料整理而成，含成体系原文引用 |
| 抓取语料 | `rag/corpus.jsonl`（259 页） | 官方文本转录镜像，属他人著作权内容 |

| 向量索引 | `rag/embeddings.npy`、`rag/embeddings_meta.jsonl` | 由语料生成，可反推文本 |
| 向量模型 | `rag/models/bge-small-zh-v1.5/` | 第三方模型权重，非本人作品 |

| 官方影像 | `官方视频/*.mp4`（4 部） | 官方版权影像 |
| 影像拆解稿 | `docs/姬子影像拆解_工作稿.md` | 含官方影像文案引用 |

| 内容 | 性质 |
